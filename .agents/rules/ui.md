## UI.

Prioritise colour-palette and theme consistency:

- Primary Font: Karla, 0.85-1rem
- Monospace Font (code/keybinds only): Fira Code, 0.85-1rem
- White (255,255,255): primary colour
- Red (200,40,40): interactive elements
- Green (60,150,60): elements toggled on

For icons, use Material Icons.

1. Layouts should be simple and organised. Do not lose feature depth.
2. Make sure descriptions are brief, simple and user-friendly. Would the average person be able to read your UI?
